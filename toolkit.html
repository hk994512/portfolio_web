Toolkit

What I Design and Build With

The architecture and engineering decisions are mine — AI just helps write some of the code alongside me. This is the current setup, grouped by where each piece fits.

Core Tech Stack

Flutter + Dart

My go-to for every mobile product — one codebase for Android and iOS, sound null safety, and a widget tree kept small enough to stay fast.

Firebase

Authentication, Firestore, Cloud Functions, push notifications, and Crashlytics — the quickest route from idea to a working backend.

Supabase

Relational PostgreSQL storage, auth, realtime, and row-level security when the data needs real structure.

REST APIs + Dio

Networking with interceptors, token refresh, and typed models, so screens never deal with raw JSON.

Hive + SQLite

Local storage for offline-first apps — Hive for quick key-value data, SQLite when queries get relational.

State & Architecture

Provider / Riverpod / Bloc

State management chosen per project — lightweight where the app is small, more structured where many screens share state.

Clean Architecture

Presentation, domain, and data layers kept separate, so features can change without breaking everything around them.

AI Tools

Claude & Claude Code

For working through architecture, reviewing code, and multi-file refactors I drive from the terminal.

ChatGPT

Fast lookups, thinking out loud, and the occasional job like reading a screenshot or sketching a UI reference.

DeepSeek

DeepSeek is my second brain: fast lookups, thinking out loud, and the occasional task like reading a screenshot or sketching a UI reference.

Codex

For generating code from natural language, agentic multi-file edits in the CLI, and quick boilerplate I'd otherwise write by hand.

Tooling & Release

Android Studio + VS Code

Daily editors, paired with Flutter DevTools to profile rebuilds, memory, and jank before users notice them.

GitHub

Where the code lives — every repo worth maintaining gets a README that explains the reasoning, not just the mechanics.

Play Console & App Store Connect

Signing, build flavors, and store submission handled end to end, so an app ships and not just runs on my device.

Design & Planning

Figma

Where a product idea becomes an interface, and where I convert designs into pixel-accurate Flutter screens.

Postman

For designing and testing APIs, especially ones where the app and backend need to stay in sync.
